# Flow Matching 推导笔记

对应 checklist 的 w0d1t0 / w0d1t1 / w0d1t2。目标是能在白板上 5 分钟推完。

## 1. 问题设定

要把简单分布 `p₀`（一般取 `N(0, I)`）变成数据分布 `p₁`。用一个 ODE 来搬运：

```
dx/dt = v_t(x),        t ∈ [0, 1]
```

从 `x₀ ~ p₀` 出发按这个 ODE 积到 t=1，得到的样本就该服从 `p₁`。

中间过程 `p_t` 叫**概率路径**（probability path）。速度场 `v_t` 与路径 `p_t` 相容的条件是连续性方程：

```
∂p_t/∂t + ∇·(p_t v_t) = 0
```

## 2. 朴素目标不可算

理想的训练目标是回归真实的边缘速度场 `u_t`：

```
L_FM(θ) = E_{t~U[0,1], x~p_t} ‖ v_θ(x, t) − u_t(x) ‖²
```

问题：`u_t` 和 `p_t` 都没有解析形式，**这个 loss 算不出来**。

## 3. 条件化：CFM 的核心技巧

引入条件变量 `z`，构造一族**我们知道解析形式**的条件路径 `p_t(x|z)`，让边缘路径是它们的混合：

```
p_t(x) = ∫ p_t(x|z) q(z) dz
```

**定理**（Lipman et al. 2022）：生成 `p_t` 的边缘速度场是条件速度场的条件期望

```
u_t(x) = E_{q(z|x)} [ u_t(x|z) ]
```

于是可以改为回归**条件**速度：

```
L_CFM(θ) = E_{t, z~q(z), x~p_t(x|z)} ‖ v_θ(x, t) − u_t(x|z) ‖²
```

**关键结论：`∇_θ L_FM = ∇_θ L_CFM`** —— 两个 loss 只差一个与 θ 无关的常数。

### 为什么梯度相等（面试常问）

展开平方项：`‖v_θ − u_t(x)‖² = ‖v_θ‖² − 2⟨v_θ, u_t(x)⟩ + ‖u_t(x)‖²`
第三项不含 θ，直接扔掉。剩下两项：

- **第一项** `E_{p_t(x)}‖v_θ(x,t)‖²`：因为 `p_t(x) = ∫p_t(x|z)q(z)dz`，
  按定义它就等于 `E_{q(z), p_t(x|z)}‖v_θ(x,t)‖²`。两边一样。✓

- **第二项** 把 `u_t(x)` 的定义代进去，贝叶斯展开 `q(z|x) = p_t(x|z)q(z)/p_t(x)`：

  ```
  E_{p_t(x)} ⟨v_θ(x,t), u_t(x)⟩
    = ∫ p_t(x) ⟨v_θ(x,t), ∫ u_t(x|z) · p_t(x|z)q(z)/p_t(x) dz⟩ dx
    = ∫∫ ⟨v_θ(x,t), u_t(x|z)⟩ p_t(x|z) q(z) dz dx        ← p_t(x) 约掉了
    = E_{q(z), p_t(x|z)} ⟨v_θ(x,t), u_t(x|z)⟩
  ```
  两边也一样。✓

**一句话直觉**：MSE 回归的最优解是条件均值。把 `v_θ(x,t)` 往带噪的目标
`u_t(x|z)` 上回归，收敛点自然是 `E[u_t(x|z) | x_t = x]`，而这恰好就是我们要的
边缘速度场。**你在回归一个不知道的量，靠的是它等于某个知道的量的条件期望。**

## 4. OT-CFM：代入具体的条件路径

取 `z = (x₀, x₁)`，`q(z) = p₀(x₀)·p₁(x₁)`（独立耦合），条件路径取**直线插值**：

```
x_t = (1 − t)·x₀ + t·x₁
```

条件速度就是对 t 求导：

```
u_t(x | x₀, x₁) = dx_t/dt = x₁ − x₀        ← 常数，不依赖 t
```

代回 L_CFM，得到最终的训练目标：

```
L = E_{t~U[0,1], x₀~N(0,I), x₁~data} ‖ v_θ((1−t)x₀ + t·x₁, t) − (x₁ − x₀) ‖²
```

训练循环就四行：采 t、采噪声、线性插值、回归 `x₁ − x₀`。

采样用 Euler 积分：`x_{t+Δt} = x_t + Δt · v_θ(x_t, t)`，从 `x₀ ~ N(0,I)` 积到 t=1。

## 5. 两个容易背错的点

### (1) "FM 的路径是直线" —— 只有**条件**路径是直线

直线的是 `x_t = (1−t)x₀ + t·x₁` 这条**给定端点后**的路径。**边缘**轨迹（真正采样时
走的那条）并不是直线，因为 `u_t(x)` 是很多条条件路径的加权平均，不同条件路径在
同一点 x 会给出不同方向。

这正是**为什么 10 步 Euler 够用、但 1 步不行**。Rectified Flow 的 reflow 就是专门
用来把边缘轨迹进一步拉直的（拉直到 1 步可用）。

被追问时这么答，比只会说"FM 路径是直线"高一个层次。

### (2) BF16 不需要 GradScaler

GradScaler 是给 FP16 的：FP16 指数位只有 5 bit，小梯度会下溢成 0，所以要放大 loss。
BF16 指数位 8 bit，和 FP32 动态范围相同（牺牲的是尾数），不会下溢。
Ada 架构上直接 `autocast(dtype=torch.bfloat16)` 即可。

### (3) FM 的 loss 有不可约下界，**绝对值不能用来判断训练好坏**

给定 `(x_t, t)`，回归目标 `x₁ − x₀` 仍然是**随机的**：

- `t=0` 时 `x_t = x₀`，此时 `x₁` 完全未知 → 目标方差 = 数据方差
- `t=1` 时 `x_t = x₁`，此时 `x₀` 完全未知 → 目标方差 = 噪声方差 = 1

最优模型输出的是条件均值 `E[x₁−x₀ | x_t, t]`，残差方差是扔不掉的。所以 loss 收敛到
`E[Var(x₁−x₀ | x_t, t)]` —— 一个 **O(1) 的正数，不会趋近 0**。

本机 Swiss Roll 实测（`notebooks/w0d3b_loss_floor.py`，12000 步）：

| | 起点 | 终点 | 变化 |
|---|---|---|---|
| loss | 2.223 | 1.967 | 只降 11.5% |
| 真实生成质量 (切片 W2) | 0.155 | 0.098 | 降 37.0% |

**loss 早早就趴平了，但生成质量还在持续变好。** 所以：

- 不要用 "loss 降到 X 以下" 当验收标准 —— 这个门槛不存在
- 要看**相对下降趋势**，或者直接监控下游指标（本项目就是 success rate）
- 只有 loss 完全不动（连 10% 都没降）才说明真有问题

顺带一提，这也是 DDPM/FM 这类模型普遍不看 loss 绝对值的原因，和判别式模型的直觉不同。

## 6. 与 DDPM 对比

| 维度 | DDPM | Flow Matching |
|---|---|---|
| 训练目标 | 预测噪声 ε | 预测速度 `x₁ − x₀` |
| 目标是否依赖 t | ε 本身不依赖，但**跨噪声层级的 loss 权重**很关键（一堆 SNR-weighting 的文献） | 条件目标是常数，天然等权 |
| 采样步数 | 100–1000 | 10–20 |
| 边缘轨迹 | 弯曲（随机游走的期望） | 接近直线（但不是严格直线，见上） |
| 代表工作 | Diffusion Policy | π0, RDT |

## 7. 一个可做的改进（也是好的面试素材）

上面用的是**独立耦合** `q(z) = p₀·p₁`，严格说这叫 conditional-OT 路径。
Tong et al. 的完整 **OT-CFM** 还会把独立耦合换成 **minibatch OT 耦合**：在一个 batch
内对 `{x₀}` 和 `{x₁}` 解一次最优传输匹配再配对，而不是随机配对。

好处：减小回归目标的方差，把边缘轨迹拉得更直，少步采样质量更好。
代价：每步多一次 batch 内的匹配（`scipy.optimize.linear_sum_assignment` 或 POT 库）。

本项目先用独立耦合跑通，这个留作消融项。
